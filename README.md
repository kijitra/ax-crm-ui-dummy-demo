# UIデモ

KIJ-1335で検討している、AIに業務を任せる管理画面のダミー実装。担当: akane。

## 起動

```sh
python3 -m http.server 8877 --bind 127.0.0.1
```

[ローカル画面](http://127.0.0.1:8877/)を開く。検証は `node scripts/check.cjs`。

## 範囲

全データは架空。DB・Cloudflare・メールに接続していない。送信・更新はページ内メモリーだけに反映し、リロードで初期化される。営業は画面を検討するための初期業務例であり、製品の対象業務を営業だけに限定していない。

- ダッシュボード: 期間内の目標、受注実績、進行中案件の金額。
- 案件: カンバンと一覧。詳細でプロパティ編集・案件別の活動。
- 活動: 顧客・案件に関連するメモ、メール、タスク、打ち合わせ。
- 業務フロー: 自動実行の設定と確認。

編集元は `index.html`。既存の8876のプレビューはこのファイルのコピーである。
remote・外部公開・本番連携はない。今後の判断は [仕様](docs/specs/brief.md) を参照。
