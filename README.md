# UIデモ

AIに業務を任せる管理画面の操作デモです。チャットからタスクや案件を確認し、そのまま関連するレコードを開いて操作できます。

[GitHub](https://github.com/kijitra/ax-crm-ui-dummy-demo)

## 起動

```sh
python3 -m http.server 8877 --bind 127.0.0.1
```

[UIデモ](http://127.0.0.1:8877/)を開き、入力済みの依頼を送信してください。`chat.html` は同じ画面への互換リダイレクトです。

## 試せること

- チャット: 自分のタスク、メール案、案件の更新案、案件データの表、操作後の結果確認。
- 案件: カンバン／一覧、顧客名・案件名の検索、ステージ・担当による絞り込み。
- 案件詳細: プロパティ編集、メモ、メール下書き、タスク、打ち合わせ作成。
- タスク: 自分のToDo／完了と、AIに任せた仕事を分けて確認。
- ダッシュボード: 受注目標、受注実績、進行中案件の金額。
- 業務フロー: 自動実行の設定とサンプル実行。

## データと実装の範囲

顧客25件、案件50件、活動100件、タスク50件、打ち合わせ20件の架空データを同梱。担当者・案件ステージ・日付・金額を分散させ、顧客と案件IDで関連付けています。「自分の対応」はakane担当分です。

外部AI、DB、Cloudflare、メールには接続しません。チャットは固定シナリオです。送信・更新はブラウザーのメモリー内だけに反映し、リロードで初期化されます。メールアドレスは予約ドメイン `.example` を使用しています。

営業は初期の業務例であり、対象を営業だけに限定するものではありません。詳細は [検討範囲](docs/specs/brief.md) と [調査メモ](docs/research.md) を参照してください。

## 検証

```sh
node scripts/check.cjs
node scripts/check-chat.cjs
```

編集元は `index.html`。外部パッケージ不要。GitHubへのソース公開と本番サービスの運用・デプロイは別です。
